A Rock Paper Scissors game using Java Script and played via the console. 5 rounds in total.  

Skills: function, if, else if, else statement, loops  

To me, it was not a simple and easy game to make. It took a long time for me to understand how function work and write the if, else if, and else statement. Through the project, it was a good practice to write the pseudo code before actually typing the code. I still stuck in some steps now but I believe I will get better. For now, please enjoy the game!  

Open the following link in web browser. Enter your five choices in the pop-ups. Right click and choose Inspect. Look for the Console and you will see the result.
https://kuma-369.github.io/Rock_Paper_Scissors/
